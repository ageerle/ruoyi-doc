# 更新日志归档

侧栏最多显示最近 **5 期月度日志**，较早记录保留在本页；顶部“更新日志”直接进入最新一期。

## 日志口径 {#scope}

2025 年 9 月起的补充记录，根据 **2026-09-08** 核对的 GitHub [ruoyi-ai 主分支快照](https://github.com/ageerle/ruoyi-ai/commit/d4ed2b867274d3f2ac08efd6041b24fd4b30af64)整理，仅包含已发布到 GitHub 的提交。

月份按 main 首父链（first-parent）的提交时间，以北京时间归档。合并提交计为一条，功能归入合入主分支的月份，不按功能分支更早的提交日期提前记录。数量覆盖该月全部主分支记录，正文选取与开发者相关的主要变化。

月度摘要不等同于独立发布版本；历史功能可能在后续重构中调整，当前使用方式以功能文档为准。2025 年 5～8 月沿用原有日志，本次未重新统计。
