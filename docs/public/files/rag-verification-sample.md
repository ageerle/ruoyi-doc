# RuoYi AI RAG 验证样例

本文档只用于验证知识库上传、解析、向量化、召回和回答链路。

## 北辰项目

北辰项目的后端服务端口是 **6039**，发布负责人是 **林小满**。项目每周三 15:00 进行例行发布检查。

## 海棠项目

海棠项目使用 **Weaviate** 保存文本向量，集合前缀为 **LocalKnowledge**。遇到检索结果为空时，应先检查向量模型是否可用，再检查 Weaviate 的 28080 端口。

## 故障处理约定

如果文档已经上传但没有生成片段，应依次检查文档解析状态、向量模型 API Key、向量维度和向量库连接。测试问题应使用文档中的明确事实，避免只问宽泛的总结题。
